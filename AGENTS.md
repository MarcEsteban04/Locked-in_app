# Locked In — project conventions

## Styling

- **NativeWind v5 (preview) + Tailwind 4.** There is no `tailwind.config.js`; Tailwind 4 puts
  configuration in CSS.
- **`src/global.css` is the single source of truth for design tokens.** Never hardcode a hex value
  in a component — add a token and use a class. ESLint warns on bare hex literals.
- `src/constants/theme.ts` is a hand-maintained TypeScript mirror of those tokens, for APIs that
  refuse a `className` (status bar, React Navigation theme, lucide/SVG `color` props). Edit both or
  they drift.
- The design language is flat — see `docs/design_prompt.xml`. **No shadows, no elevation, no blur,
  no gradients on elements.** Hierarchy comes from scale, weight and solid colour blocks.
- Dark mode works through `@media (prefers-color-scheme: dark)` overriding the `:root` variables.
  Do not add a theme context or a manual theme toggle without discussing it first.
- New primitives go in `src/components/ui/` and follow the existing shape: a `const` map of variant
  classes, then `cn(variantClasses, className)` so callers can always override.

## Do not change without checking

- **`lightningcss` is pinned to exactly `1.30.1` via `devDependencies` and an npm `override`.**
  1.30.2 breaks the native CSS compile with `failed to deserialize; expected an object-like struct
named Specifier`, and `react-native-css` swallows its own guard for this in a `catch`, so the
  error is unattributable. Do not widen this range.
- **`postcss.config.js` must exist.** NativeWind delegates CSS to Expo's transform, so without
  `@tailwindcss/postcss` registered there, no utility classes are generated — silently, on every
  platform. A build that "succeeds" but renders unstyled is this.
- `nativewind-env.d.ts` is generated by the metro plugin and is committed on purpose; typechecking
  fails without it.

## Verifying a change

Bundling for web alone is not enough — native runs an extra CSS compile step that web skips:

```bash
npx tsc --noEmit
npx eslint .
npx expo export --platform ios --clear --output-dir <tmp>
```
